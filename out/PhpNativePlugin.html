PhpNativePlugin Documentation

A DroidScript plugin that enables PHP 8 as the business logic brain with Java as executor and DroidScript as hardware interface.

Architecture: PHP 8 (Brain) → Java Plugin (Executor) → DroidScript (Hardware Interface)

Setup Requirements

Important: The PHP binary (libphp.so) must be placed in your app's jniLibs folder. It is NOT bundled in the PPK to keep plugin size small (~36KB vs ~31MB).

Initialization Methods

GetVersion()
Returns: String - Plugin version number
Returns the current version of the plugin.
IsReady()
Returns: Boolean - true if PHP engine is ready
Checks if the PHP binary has been extracted and is ready for execution.
Start(callback)
Parameters: callback - Function called when ready
Initializes the PHP engine. Call this before using any PHP features.
plg.Start(function() {
    console.log("PHP engine ready!");
});
AutoStart(appFolder)
Parameters: appFolder - App folder name containing app.php
Returns: Boolean - true if app.php exists and will auto-start
Automatically starts the PHP engine and runs app.php if it exists in the specified app folder.
if (plg.AutoStart("MyApp")) {
    console.log("App will auto-start");
}

App Folder Management

SetApp(folder)
Parameters: folder - App folder name
Sets the current app folder. Creates the folder if it doesn't exist.
GetAppPath()
Returns: String - Full path to current app folder
Returns the absolute path to the current app's folder.
HasAppPhp()
Returns: Boolean - true if app.php exists
Checks if app.php exists in the current app folder.
CopyPhpToApp()
Returns: String - Result message
Copies the default PHP files (logic.php, router.php, ui_core.php, app.php) from plugin assets to the current app folder.
GetPathInfo()
Returns: String - JSON with path information
Returns diagnostic information about plugin and app paths.

PHP Execution

RunApp()
Executes the app.php file in the current app folder.
CallPhp(action, params, callback)
Parameters:
• action - Action name to execute
• params - JSON string of parameters
• callback - Function receiving result
Calls PHP logic with specified action and parameters. PHP should return JSON response.
plg.CallPhp("getData", '{"id": 123}', function(result) {
    var data = JSON.parse(result);
    console.log(data);
});

Debugging Methods

DebugPhp()
Returns: String - Comprehensive debug information
Returns detailed diagnostic information including:
• PHP binary path and status
• App folder path and contents
• Plugin directory information
• File permissions and sizes 
var debug = plg.DebugPhp();
app.Alert(debug, "PHP Debug Info");
RunPhpTest()
Returns: String - Raw PHP test output
Runs a simple PHP test script and returns raw output. Useful for verifying PHP execution works.
var result = plg.RunPhpTest();
// Should return: "PHP_TEST_OK|8.x.x|..."
console.log(result);

UI Rendering

RenderUI(jsonLayout, parent)
Parameters:
• jsonLayout - JSON string defining UI layout
• parent - Parent DroidScript layout object
Renders native Android UI components from JSON definition returned by PHP.
var layout = '{"type":"LinearLayout","children":[{"type":"TextView","text":"Hello"}]}';
plg.RenderUI(layout, lay);
UpdateView(id, property, value)
Parameters:
• id - View ID
• property - Property name to update
• value - New value
Updates a property of a rendered view by its ID.
GetViewText(id)
Returns: String - Text content of view
Gets the text content of a view by ID.
SetViewText(id, text)
Parameters:
• id - View ID
• text - New text content
Sets the text content of a view by ID.

Overlay System

ShowOverlay(jsonLayout)
Parameters: jsonLayout - JSON string defining overlay UI
Shows a floating overlay window with the specified UI layout.
HideOverlay()
Hides the currently visible overlay.
RemoveOverlay()
Completely removes the overlay from memory.

Sensor Access

GetAccelerometer(callback)
Parameters: callback - Function receiving {x, y, z} values
Gets current accelerometer readings.
GetGyroscope(callback)
Parameters: callback - Function receiving {x, y, z} values
Gets current gyroscope readings.
GetMagnetometer(callback)
Parameters: callback - Function receiving {x, y, z} values
Gets current magnetometer readings.
GetGPS(callback)
Parameters: callback - Function receiving {lat, lng, alt, acc} values
Gets current GPS location.
GetBattery(callback)
Parameters: callback - Function receiving battery percentage
Gets current battery level.

Example Usage

// Initialize plugin
var plg = app.LoadPlugin("PhpNativePlugin");

function OnStart() {
    // Set app folder and check for app.php
    plg.SetApp("MyApp");
    
    // Copy PHP files if needed
    if (!plg.HasAppPhp()) {
        plg.CopyPhpToApp();
    }
    
    // Start PHP engine
    plg.Start(function() {
        console.log("PHP Ready!");
        
        // Debug information
        console.log(plg.DebugPhp());
        
        // Test PHP execution
        console.log(plg.RunPhpTest());
        
        // Call PHP logic
        plg.CallPhp("getUI", '{}', function(result) {
            var layout = app.CreateLayout("Linear", "VCenter,FillXY");
            plg.RenderUI(result, layout);
            app.AddLayout(layout);
        });
    });
}

PHP File Structure

Required files in app folder:
• app.php - Main application entry point
• logic.php - Business logic handler
• router.php - Action routing
• ui_core.php - UI component definitions
