simple.php

Beginner-friendly helper functions for quick Android app development.

require_once 'simple.php'; — 225+ functions covering UI, sensors, HTTP, media, hardware, and more.

Page Builders

page()

VerticalLayout page(string $title, array $content, array $options = [])

Creates a scrollable page with a title and vertically stacked content.

OptionTypeDefaultDescription
paddingint30Page padding in dp
titleColorstring#4ec9b0Title text color
titleSizeint24Title font size in sp
backgroundstring#1e1e1eBackground color
Example
return page("Settings", [
    label("Adjust your preferences"),
    checkbox("notifications", "Enable notifications"),
    button("Save", "onSave"),
], ['padding' => 20]);

card()

VerticalLayout card(string $title, array $content)

Groups content in a card-style container with rounded corners and dark background.

Example
return page("Dashboard", [
    card("User Info", [
        label("John Doe", ['bold' => true]),
        label("john@email.com", ['color' => '#888']),
    ]),
    card("Stats", [
        label("Posts: 42"),
    ]),
]);

Sensors

All sensor functions are asynchronous — they trigger a DroidScript sensor read and call your PHP callback with the results.

gps()

array gps(string $callback) async

Get GPS location. Callback receives: lat, lng, altitude.

battery()

array battery(string $callback) async

Get battery info. Callback receives: level (int), charging (bool).

compass() / scanBarcode()

array compass(string $callback) async
array scanBarcode(string $callback) async

Compass returns azimuth, pitch, roll. Barcode returns code.

Sensor Example
function getLocation($p) { return gps("onLocation"); }
function onLocation($p) {
    return setText("loc", "📍 " . $p['lat'] . ", " . $p['lng']);
}

Network & HTTP

httpGet()

array httpGet(string $url, string $callback) async

HTTP GET request. Callback receives response (string), status (int).

httpPost()

array httpPost(string $url, string $body, string $callback, string $headers = '') async

HTTP POST request with body and optional headers.

Example: API Call
function fetchData($p) {
    return httpGet("https://api.example.com/data", "onDataReceived");
}
function onDataReceived($p) {
    $data = json_decode($p['response'], true);
    return setText("result", $data['message']);
}

View Property Helpers

Read and modify view properties after initial render. All use the view's id.

Universal get / set / update

void get(string $id, string $property, string $callback) async
array set(string $id, string $property, $value)
array update(string $id, array $properties)

Universal property access. update() sets multiple properties at once.

Example
// Set one property
return set("my_label", "text", "New text");

// Set multiple properties
return update("my_label", [
    "text" => "Updated!",
    "textColor" => "#4CAF50",
    "bold" => true
]);
