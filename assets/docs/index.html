PhpNativePlugin

Write native Android apps in PHP — no Java, no XML layouts.

What is PhpNativePlugin?

A DroidScript plugin that lets you build fully native Android UIs using PHP. Your PHP code defines the view tree as structured arrays, and the plugin renders real Android widgets — not WebViews.

Two API levels: Pick the style that suits your skill level, or mix both.
APIStyleBest for
simple.php Procedural helper functions — page(), button(), label() Quick prototyping, beginners
ui_core.php OOP fluent builder — new Button("OK")->setOnClick("go") Complex apps, full control

Quick Start

hello.php (simple API)
require_once 'simple.php';

class App {
    function index() {
        return page("#1e1e1e", [
            label("Hello, PHP!", ["textSize" => 28, "textColor" => "#4ec9b0"]),
            button("Tap Me", "onTap"),
        ]);
    }

    function onTap($p) {
        return toast("Button pressed!");
    }
}
hello.php (OOP API)
require_once 'ui_core.php';

class App {
    function index() {
        return (new VerticalLayout())
            ->setBackground("#1e1e1e")
            ->setPadding([20,20,20,20])
            ->addChild(
                (new TextView("Hello, PHP!"))
                    ->setTextSize(28)
                    ->setTextColor("#4ec9b0")
            )
            ->addChild(
                (new Button("Tap Me"))
                    ->setOnClick("onTap")
            );
    }

    function onTap($p) {
        return snackbar("Button pressed!");
    }
}

Architecture

┌─────────────────┐ │ Your PHP Code │ App class with index() + event methods └───────┬─────────┘ │ returns JSON view tree / action arrays ┌───────▼─────────┐ │ PHP Interpreter │ Embedded php-cgi (arm64 / armv7) └───────┬─────────┘ │ JSON over stdin/stdout ┌───────▼─────────┐ │ PhpNativePlugin │ Java ↔ DroidScript bridge └───────┬─────────┘ │ renders native Android Views ┌───────▼─────────┐ │ Android UI │ Real widgets: Button, TextView, RecyclerView… └─────────────────┘

How It Works

  1. index() — Your App class's index() method returns a view tree (components or arrays).
  2. Render — The plugin converts the tree into native Android views on the UI thread.
  3. Events — Button clicks call PHP methods (e.g., onTap($params)) with event data.
  4. Actions — Event handlers return action arrays (toast, updateView, animate…) that the plugin executes.
  5. State — Read view state synchronously with getViewProperty() or _getText().

Installation

  1. Copy PhpNativePlugin/ into DroidScript's plugin folder
  2. Create a new DroidScript project
  3. In your JS file: app.LoadPlugin("PhpNativePlugin")
  4. Write your PHP app class, require_once the API you want
  5. Run from DroidScript — your native PHP app launches!
