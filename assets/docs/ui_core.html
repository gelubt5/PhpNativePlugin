ui_core.php

Full-featured component library with fluent API for Android apps.

require_once 'ui_core.php'; — OOP components with chained setters, action helpers, and 40+ native view types.

Component (Base Class)

All UI components extend Component. It provides the fluent builder pattern (chained setters) and action helpers for runtime property manipulation.

Fluent API Pattern
// All setters return $this for chaining
$text = (new TextView("Hello!"))
    ->setId("greeting")
    ->setTextColor("#4ec9b0")
    ->setTextSize(24)
    ->setBold(true)
    ->setPadding([16, 8, 16, 8])
    ->setBackground("#2d2d30")
    ->setCornerRadius(8)
    ->setOnClick("onGreetingClick");

Common Setters (all components)

MethodDescription
setId($id)Unique identifier for later reference
setBackground($color)Background color (hex)
setCornerRadius($dp)Rounded corners
setElevation($dp)Material elevation shadow
setAlpha($float)Opacity (0.0 - 1.0)
setMargin($px)Outer margin
setPadding($arr)Inner padding [left, top, right, bottom]
setWeight($w)Layout weight for proportional sizing
setWidth($w) / setHeight($h)Dimensions ("match_parent", "wrap_content", or dp)
setGone() / setInvisible()Visibility control
setOnClick($method)Click handler (PHP method name)
setOnLongClick($method)Long-click handler
Magic setters: Any set*() call is handled by __call() magic method. You can set any attribute, e.g. ->setCustomAttr("value").

class App {

        $list = (new ListView())
            ->setId("todo_list")
            ->items([
                ['title' => 'Buy groceries', 'done' => false],
                ['title' => 'Walk the dog', 'done' => true],

    }

Standalone Functions

View State

Synchronous view property access via the view state file.

mixed getViewProperty(string $viewId, string $property, $default = null)

Read a property synchronously. Property names use underscore prefix: _getText, _getChecked, etc.

array getViewState(string $viewId)

Get all properties of a view as an associative array.

array updateView(string $viewId, array $attributes)

Update multiple properties of a view. Keys map to setter names (without "set" prefix).

array updateMany(array $updates)

Update multiple views. Each entry: ['id' => $id, 'props' => [...]].

array batch(...$actions)

Execute multiple actions in one response.

Example: View State
function onSubmit($p) {
    $email = getViewProperty("email", "_getText");
    $agree = getViewProperty("terms", "_getChecked");

    if (!$agree) return toast("Accept terms first");

    return batch(
        toast("Submitted!"),
        updateView("status", ["text" => "Done", "textColor" => "#4CAF50"])
    );
}

Native / Sensor API

Two paths available: Pure Java handlers (75 handlers, recommended) or DroidScript bridge (legacy).

Recommended: Use native($type, $callback, $params) for pure Java execution — faster and no JavaScript bridge.

Core Function

native() — Pure Java Handler
// Call any of 75 native handlers directly in Java
return native("battery", "onBattery");

// With parameters
return native("http", "onResponse", [
    "url" => "https://api.example.com/data",
    "method" => "GET"
]);

// Callback receives result
function onBattery($params) {
    $level = $params['level'];
    return toast("Battery: {$level}%");
}
